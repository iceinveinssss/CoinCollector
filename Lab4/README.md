# Лабораторная работа 4

## Структурные паттерны: Компоновщик и Декоратор

Предметная область: игра «Собиратель монет».

### Использованные паттерны

1. Компоновщик (Composite) — объединяет отдельные игровые объекты и группы объектов в единую иерархию. GameObjectGroup содержит объекты общего интерфейса IGameObject.
2. Декоратор (Decorator) — динамически добавляет объектам дополнительные возможности без изменения их исходных классов. ScoreDecorator добавляет бонусные очки, а AnimationDecorator имитирует включение анимации.

Декораторы можно комбинировать и последовательно оборачивать один объект несколькими дополнительными слоями поведения.

### Результат

Реализована иерархия игровых объектов с использованием Компоновщика и возможность динамического расширения поведения объектов с помощью Декоратора.
