# Лабораторная работа 1

## Порождающие паттерны: Строитель

Предметная область: игра «Собиратель монет».

### Цель

Реализовать создание игрового объекта с использованием порождающего паттерна «Строитель» (Builder).

### Реализация

В проекте используются классы:

- **Game** — продукт, описывающий игровую конфигурацию;
- **GameBuilder** — строитель объекта Game;
- **Player** — игрок;
- **Coin** — игровая монета;
- **Position** — координаты объекта.

GameBuilder позволяет пошагово настроить размер игрового поля, сложность, параметры игрока, его начальную позицию и количество монет, после чего метод Build() создаёт готовый объект Game.

### Запуск

Требуется .NET 8 SDK.

Из каталога проекта:

    dotnet run
