## О проекте

Проект посвящён разработке приложения «Собиратель монет» — аркадной игры, в которой игрок управляет персонажем, собирает монеты, получает очки и взаимодействует с игровыми объектами.

В рамках лабораторных работ проект постепенно развивается с применением объектно-ориентированного подхода и паттернов проектирования.

## Структура проекта

Каждая лабораторная работа находится в отдельной папке:

- **Lab1** — порождающий паттерн «Строитель».
- **Lab2** — порождающие паттерны «Абстрактная фабрика» и «Прототип».
- **Lab3** — структурные паттерны «Адаптер» и «Мост».
- **Lab4** — структурные паттерны «Компоновщик» и «Декоратор».
- **Lab5** — структурные паттерны «Фасад» и «Приспособленец».

## Используемые технологии

- C#
- .NET 8
- Объектно-ориентированное программирование
- Паттерны проектирования GoF

## Запуск

Для запуска отдельной лабораторной работы необходимо перейти в каталог соответствующего проекта и выполнить:

```bash
dotnet run
```

Например:

```bash
cd Lab5/CoinCollector
dotnet run
```
