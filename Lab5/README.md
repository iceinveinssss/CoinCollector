# Лабораторная работа 5

## Структурные паттерны: Фасад и Приспособленец

Предметная область: игра «Собиратель монет».

### Использованные паттерны

**Фасад (Facade)** предоставляет упрощённый интерфейс для запуска игры и скрывает детали работы подсистем ввода, отображения, столкновений и подсчёта очков.

**Приспособленец (Flyweight)** позволяет разделять общие данные большого количества однотипных монет. CoinFlyweight хранит общие данные: внешний вид, звук и стоимость. Отдельный Coin хранит только изменяющееся состояние — координаты.

### Структура Фасада

Program обращается к GameFacade, а тот управляет GameInput, GameRenderer, CollisionSystem и ScoreManager.

### Структура Приспособленца

CoinFactory хранит кэш объектов CoinFlyweight. Несколько монет могут ссылаться на один и тот же объект приспособленца, если их общие характеристики совпадают.

### Результат

Реализовано упрощённое управление подсистемами игры через Фасад и совместное использование общих данных однотипных монет через Приспособленец.
