# Лабораторная работа 2

## Порождающие паттерны: Абстрактная фабрика и Прототип

Предметная область: игра «Собиратель монет».

### Использованные паттерны

1. Абстрактная фабрика — общий интерфейс создания связанных игровых объектов: персонажа и монеты.
2. Прототип — создание новых экземпляров персонажа и монеты путём клонирования заранее подготовленных объектов-прототипов.

### Игровые семейства

- ClassicGameFactory создаёт классического героя и золотые монеты.
- FantasyGameFactory создаёт рыцаря и магические кристаллы.

Каждая фабрика формирует согласованное семейство объектов. Объекты создаются копированием соответствующих прототипов.

### Запуск

Требуется .NET 8 SDK.

Из каталога Lab2/CoinCollector выполните:

    dotnet run
